# NikitaBot 🎬 • Autonomous Instagram Reels & Posts AI Agent

Автономный ИИ-агент для автоматического мониторинга, бесплатного скрейпинга, транскрибации и мультимодального анализа Instagram Reels и постов целевых профилей с мгновенными оповещениями в Telegram и интерактивным веб-дашбордом.

---

## 🌟 Возможности системы

1. **Бесплатный скрейпинг без платных API:**
   - Мониторинг заданных Instagram-аккаунтов через `Instaloader` и `yt-dlp`.
   - Автоматическая ротация сессий и заголовков User-Agent для защиты от блокировок.
   - Загрузка видеопотоков Reels (MP4), каруселей, описаний, хэштегов и метрик.

2. **Мультимодальный ИИ-конвейер анализа:**
   - **Speech-to-Text:** локальная транскрибация аудиодорожки видео через `Whisper` / `faster-whisper`.
   - **Visual Hook Analysis:** компьютерное зрение и мультимодальные LLM оценивают первые 3 секунды видеоряда (динамика, цепляющий заголовок, темп монтажа).
   - **Sentiment & Virality:** оценка эмоционального тона, виральности и структуры сценария (хук → ценность → призыв к действию).

3. **Telegram-оповещения:**
   - Мгновенная отправка карточки нового Reels в ваш канал/чат: превью, краткая суть, транскрипт, оценка хука и прямая ссылка.

4. **Интерактивный Glassmorphism веб-дашборд:**
   - Просмотр отсканированных Reels в реальном времени.
   - Список отслеживаемых аккаунтов со статусами (`Active`, `Scanning`, `Paused`).
   - Живой лог действий автономного агента и контроль лимитов.
   - Модальные окна для детального разбора каждого ролика.

## 🚀 Быстрый запуск интерактивного макета дашборда

Дашборд работает на стандартных модулях Python 3 и готов к запуску прямо сейчас:

```bash
cd /home/bah/.gemini/antigravity/scratch/NikitaBot
python3 server.py --port 8080
```

После запуска откройте в браузере:
👉 **[http://localhost:8080](http://localhost:8080)**

В интерфейсе вы можете:
* Просмотреть карточки разобранных Reels с оценкой хуков и транскриптами.
* Нажать **«⚡ Запустить сканирование»** для симуляции реального цикла работы агента с обновлением прогресс-бара и логов.
* Открыть подробный разбор ролика (**«Подробный разбор & Транскрипт»**).
* Протестировать отправку алерта в Telegram (**«✈️»**).
* Добавить новый профиль в очередь мониторинга (**«+»**).

## ⚙️ Настройка окружения

Скопируйте пример переменных окружения:

```bash
cp .env.example .env
```

Заполните ключи:
* `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота (из @BotFather).
* `TELEGRAM_CHAT_ID` — ID вашего чата или канала.
* `GEMINI_API_KEY` или `OPENAI_API_KEY` — ключ для мультимодального анализа контента.
